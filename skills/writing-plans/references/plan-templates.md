# Шаблоны плана реализации

## Заголовок документа плана

```markdown
# План реализации: [Название фичи]

> **Для агентов:** Используй скилл executing-plans для реализации этого плана задача за задачей. Шаги используют синтаксис чекбоксов (`- [ ]`) для отслеживания.

**Цель:** [Одно предложение описывающее что это строит]

**Архитектура:** [2-3 предложения о подходе]

**Ключевые файлы / стек:** [Основные технологии/конфиги — берётся из CLAUDE.local.md проекта]

---
```

## Структура задачи

```markdown
### Задача N: [Одно предложение — что делает эта задача]

- [ ] Изменить `путь/к/файлу.ext`: [конкретное изменение, с кодом/конфигом]
- [ ] Запустить верификацию: `команда` — ожидаемый результат: [что именно должно вывестись/произойти]
```

Шаг с тестом добавляется только если в проекте принято писать тесты — как обычная задача той же гранулярности (`Написать тест X` → `Запустить и убедиться что проходит`), а не как обязательная часть каждой задачи.
