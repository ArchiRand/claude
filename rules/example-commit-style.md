# Формат коммитов

> Действующее правило для рабочих реп с трекером (klone-mobile и т.п.).
> В личных проектах без задач в трекере — своё соглашение, см. скилл проекта
> (например `intellij-plugin-dev` использует `fix:`/`feat:` без тикета).

## Формат сообщения

```
краткое описание на русском языке. <ticket>
```

где `<ticket>` — номер задачи вида `KA-12345`.

- Описание — на русском, до 150 символов, в стиле (`добавлено`, `исправлено`, `обновлено`).
- После тикета точки нет, висящих пробелов нет.

## Где взять номер задачи

Из имени ветки. Регексп для извлечения (под формат `KA-XXXX`):

```
[A-Z]+-[0-9]+
```

Команда:
```bash
git branch --show-current | grep -oE '[A-Z]+-[0-9]+' | head -1
```

Если в имени ветки номера нет — сообщи пользователю и напомни что формат должен быть вида: `KA-XXXX`.

## Хорошие примеры сообщений

```
Добавлен патчинг цен для адвент пасса, настроенного из тулы. KA-28113
Исправлен баг установки startDate в FeatureContainer. KA-28113
```

## Плохие примеры сообщений
```
патчинг цен. KA-28113
баг установки startDate
```

## Что НЕ пишем

- Не пишем английский текст в самом сообщении коммита — только русский.
- Не пишем совсем уж короткие сообщения без необходимости.
